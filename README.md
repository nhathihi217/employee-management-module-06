# Employee Management - Module 6

Spring MVC application using Thymeleaf for employee CRUD views.

## Pages

- `/employees/list`: list all employees and contain search controls
- `/employees/add`: validated add-employee form
- `/employees/search?name=...&department=...`: search employees

## Run

```bash
mvn spring-boot:run
```

Open http://localhost:8080/employees/list
